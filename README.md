# Exemplos Práticos de HTML5 - Desenvolvimento Web

Repositório criado para fins acadêmicos com o objetivo de demonstrar, de forma prática, a estrutura e o comportamento de elementos HTML abordados em apresentação em sala de aula.

---

## 📌 Conteúdo Demonstrado

* **Página Principal (`home.html`):**
  * Índice centralizado conectando os tópicos e demonstrações do projeto.

* **Estruturas de Listas (`lists/lists.html`):**
  * Listas não ordenadas (`<ul>` e `<li>`)
  * Listas ordenadas com variações de atributos (`<ol type="...">`)
  * Listas de descrição/definição (`<dl>`, `<dt>`, `<dd>`)

* **Imagens Semânticas com Legenda (`figures/figures.html`):**
  * Encapsulamento de mídia independente com `<figure>`
  * Legendas descritivas associadas via `<figcaption>`

* **Imagens Responsivas e Caixas Expansíveis (`details/details.html`):**
  * Carregamento adaptativo de imagens com `<picture>` e `<source>` (resolução e formatos)
  * Caixa expansível interativa nativa com `<details>` e `<summary>`

* **Estrutura de Texto e Hierarquia (`articles/articles.html`):**
  * Hierarquia tipográfica completa de títulos (`<h1>` até `<h6>`)
  * Blocos autônomos e semânticos de conteúdo com `<article>`
  * Estilização pontual de trechos de texto em linha com `<span>`

* **Tabelas e Dados Tabulares (`tables/tables.html`):**
  * Estruturação de dados com `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`

* **Estruturação Semântica Geral (`struct/struct.html`):**
  * Divisão moderna de layout utilizando `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>`

* **Mídia Nativa com Base64 (`media/media.html`):**
  * Reprodução embutida de vídeo (`<video>`, `<source>`) com parâmetros `controls`, `autoplay`, `muted` e `loop`
  * Reprodução embutida de áudio (`<audio>`, `<source>`) com controles nativos
  * Demonstração de mídias incorporadas via Data URI (Base64) sem dependência externa

* **Destaque e Separação de Conteúdo (`emphasis/emphasis.html`):**
  * Marcação semântica de importância (`<strong>`) e ênfase tonal (`<em>`)
  * Realce de relevância (`<mark>`) e anotações secundárias (`<small>`)
  * Divisores temáticos com linha horizontal (`<hr>`)
